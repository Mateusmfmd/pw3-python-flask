# Estudos de Python e Flask

Coleção progressiva de aulas e exercícios sobre Python, Flask, templates, arquivos estáticos, arquitetura MVC, banco de dados e operações CRUD.

## Organização

As pastas representam etapas do aprendizado, incluindo:

- Introdução ao Flask
- Templates e arquivos estáticos
- Arquitetura MVC e requisições
- Conexão e leitura de dados no banco
- Cadastro, edição e exclusão em CRUD

## Como estudar

1. Escolha uma pasta de aula.
2. Leia os arquivos Python e templates na ordem apresentada.
3. Crie um ambiente virtual para o exercício.
4. Instale as dependências indicadas no próprio exemplo.
5. Execute a aplicação Flask e acompanhe as rotas.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install flask
flask --app app run --debug
```

Os exercícios são independentes e podem usar estruturas ou dependências diferentes; verifique cada pasta antes de executar.
